# NBA Defensive Vision

A computer vision and basketball analytics project for reconstructing defensive matchups from NBA broadcast footage.

## Project Goal

The goal is to identify and track NBA players from broadcast video, map their positions to real court coordinates, infer defensive matchups, and ultimately produce a possession-level defensive impact metric.
